# 1337x Ratings Extension

Adds IMDb and Rotten Tomatoes ratings to 1337x torrent result tables using the OMDb API.

## Install

1. Open your Chromium-based browser's extensions page.
2. Enable developer mode.
3. Load this folder as an unpacked extension.
4. Open the extension options page and add your OMDb API key.

## Settings

- OMDb API key
- Cache retention in days, defaulting to 60
- Rating display mode: IMDb, Rotten Tomatoes, or both
